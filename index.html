GitHub Project & Android APK Build Guide

1. GitHub Repository Remote Setup

Your local Git repository is initialized with all source files. To push to your GitHub account:

git remote add origin https://github.com/YOUR_USERNAME/readify-broadsheet.git
git branch -M main
git push -u origin main

2. Building Android APK via Capacitor

This project is configured with Capacitor CLI for compiling into a native Android APK:

npm install
npx cap add android
npx cap copy android
npx cap open android  # Opens in Android Studio to build APK

3. Formats Supported

Includes PDF parsing via PDF.js, EPUB parsing via ePub.js, TXT, Markdown, HTML, FB2, and Web Speech API Text-to-Speech audiobook playback.
